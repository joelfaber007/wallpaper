# Wallpaper group p1

| Group | `p1` |
| --- | --- |
| Orbifold | ○ |
| Lattice | oblique, set by `a`, `b`, `gamma` |
| Point group | $C_{1}$ |
| Copies of the fundamental domain in a cell | 1 |
| Classes of rotation centre | none |
| Directions of mirror line | none |
| Directions of glide axis | none |

The lattice is spanned by

```math
\mathbf{a}_1 = a, \quad \mathbf{a}_2 = b\,e^{i\gamma}
```

## The moves

Every move is an isometry of the plane: a turn, perhaps after a flip, then a shift. With the point as the complex number $z = x + iy$ it is

```math
z \mapsto e^{i\theta} z + t \quad\text{or}\quad z \mapsto e^{i\theta}\bar{z} + t
```

the second for a move that turns the plane over: a mirror or a glide.

One call applies one of these, drawn at random. Here $a$, $b$ and the basis are as above (after the pair is reduced to the shortest pair spanning the same lattice).

| Move | Map |
| --- | --- |
| translation by +a1 | $z \mapsto z + \mathbf{a}_1$ |
| translation by -a1 | $z \mapsto z - \mathbf{a}_1$ |
| translation by +a2 | $z \mapsto z + \mathbf{a}_2$ |
| translation by -a2 | $z \mapsto z - \mathbf{a}_2$ |
| translation by +(a1 + a2) | $z \mapsto z + \mathbf{a}_1 + \mathbf{a}_2$ |
| translation by -(a1 + a2) | $z \mapsto z - \mathbf{a}_1 - \mathbf{a}_2$ |

Each translation is offered in both directions so the walk does not drift off to infinity; the turns, mirrors and glides need no reverse, since repeating them cycles back.

## How often each move is drawn

p1 has only translations. Their shares are set so the walk spreads at the same rate in every direction: a hexagonal lattice draws all six equally, and a rectangular one never steps along the diagonal.

## Works with

- `p1_fold` folds every point into one copy of the fundamental domain.
- `p1_scatter` carries a folded point to a random copy within `reach`, even across the whole of it in one step.

Give every plugin of the group the same lattice parameters, or their tiles, domains and special positions will not line up.
